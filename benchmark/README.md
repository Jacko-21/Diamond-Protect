# Benchmark des sites de sécurité privée

Veille réalisée le 24/10/2026 pour préparer la maquette du site de Diamond Protect.

- `index.html` : la page interactive du benchmark (28 sites, fiches notées, tendances, diagnostic du site actuel, recommandations). Publiée en artifact : https://claude.ai/artifact/WQ6XXqBYHpnVcNHu2HPHBQ
- `img/` : captures des pages d'accueil (1440 × 900, réduites à 720 × 450), relevées le 24/10/2026.
- `donnees-extraites.json` : données relevées automatiquement sur chaque page d'accueil (title, meta, H1, H2, menu, boutons d'action, téléphone, polices, couleurs, données structurées).

Les notes sur 5 sont des notes d'analyste (subjectives) qui servent à comparer les sites entre eux.
